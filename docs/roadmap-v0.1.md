# Roadmap V0.1

## Phase 1 — Foundation
- Problem statement and target users validated.
- Domain assumptions and constraints documented.
- Initial impact hypothesis defined.

## Phase 2 — Architecture
- Domain model and data boundaries documented.
- Security, privacy and safety risks reviewed.
- ADRs created for significant technical decisions.

## Phase 3 — MVP
- Smallest end-to-end workflow implemented.
- Automated tests cover critical paths.
- Observability and error handling are present.

## Phase 4 — Validation
- Pilot protocol defined.
- Baseline and KPI collection enabled.
- Evidence and limitations documented.

## Phase 5 — Release
- Release checklist from HashCode Global Impact completed.
- CHANGELOG and documentation updated.
- V0.1 tagged only after validation gates pass.
