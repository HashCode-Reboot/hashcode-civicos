# Contribuer à CivicOS

CivicOS est un projet de recherche et de construction collaborative. Commencez par le programme central : https://github.com/HashCode-Reboot/hashcode-contributors.

## Avant de contribuer

1. Comprendre le problème traité.
2. Vérifier les issues et missions existantes.
3. Éviter de construire une fonctionnalité sans hypothèse ou besoin documenté.
4. Ne jamais utiliser de données réelles sensibles dans un prototype sans cadre approprié.

## Pull Request

Décrire le problème, la solution, les limites, les tests et l'impact attendu. Toute contribution importante doit être documentée.
